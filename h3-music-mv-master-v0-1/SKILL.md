# 劇情型音樂 MV 提示詞總控

以歌曲為時間軸，產出可供人工製作的故事、資產提示詞、逐鏡關鍵幀提示詞、MiniMax H3 提示詞及桌面版 HTML。HTML 介面與製作說明使用繁體中文；每份可提交模型的圖片與 H3 提示詞都提供繁體中文、英文兩版，兩版敘事事實、鏡頭動作與聲音設定必須一致。

## 工作邊界

- 本流程只撰寫提示詞、分鏡與製作說明；不呼叫生圖或生影片工具，不宣稱尚未產出的素材已生成或通過人工審查。
- 用戶提供的歌詞、畫面文字、角色設定及指定條件應原樣保留。缺少會影響故事或切點的必要素材時，請用戶補充，不憑空編造歌詞、圖片內容或音訊事件。
- 歌曲於後期剪輯鋪入。預設 H3 僅接收本鏡頭首幀，產生畫面同步的現場聲；不傳入歌曲或其他音訊參考，non_diegetic_music 固定為 N/A。用戶明確要求其他聲音模式時再調整。

## 依據與優先規則

1. 用戶在本次任務的明確要求優先於本 skill 的預設。
2. 英文 H3 提示詞依本專案 h3-prompt-writing 的官方 SKILL.md 與 references/base-en.txt。I2VA 必須使用官方首幀對齊首行、欄位順序及引用標籤；預設一條提示詞對應一個連續的 [Shot 1]。不再預設使用無時間碼相容模式。
3. 本 MV 流程的劇情、單鏡、現場聲和後製歌曲規則在官方結構內補充內容，不改寫官方欄位名與首幀對齊首行。
4. 繁體中文 H3 對照版保留相同的英文首行、欄位名與引用標籤；欄位內的敘述翻為繁體中文。它是本專案的中文對照版，不冒稱為官方英文範本。中英文 H3 的時間、人物、動作、鏡位及聲音設定逐項一致。
5. 若用戶指定其他 H3 模式或與官方結構不同的格式，先套用對應官方模式；無法兼容的部分在製作說明中指出，不把自訂格式稱為官方格式。

H3 具體模板與雙語對照規則見 references/chinese-h3.md。官方 h3-prompt-writing 的英文參考檔維持原文。

- 歌曲、故事與切點：references/song-to-mv.md。

- 人物表演與動作物理：有人物鏡頭時讀 references/live-action-performance.md；場面調度需要深入設計時讀 references/cinematic-scene-direction.md。
- 整曲景別與導演曲線：需要全片節奏規劃時讀 references/global-director-score.md。

本 skill 已內含故事規劃、關鍵幀及真人表演規則，可直接使用。若另外安裝 simple-story-mv-maker 或 gpt-image-2-cinematic-frames，可參考其專項建議，但不以它們作為啟動條件；其建議不得覆蓋本頁的工作邊界與 H3 格式。

## 預設製作設定

- 劇情型真人 MV；主角一名，重要配角最多一名。以一個主要目標、障礙、核心道具、認知變化和結尾行動建立故事，可依用戶素材調整。
- 畫幅 16:9，關鍵幀提示詞目標尺寸 3840×2160；實際圖片輸出尺寸以用戶使用的工具能力為準。
- 每個 H3 生成單元為一個獨立鏡頭，規劃 4–15 秒；在故事、樂句和可執行動作允許時優先 10–15 秒。需配合用戶實際使用介面的時長選項。
- 每鏡使用一張獨立且可自然起動的首幀。相鄰鏡頭保持故事事實與資產一致，但不要求後鏡精確繼承前鏡的尾幀姿勢。

## 工作流程

### 1. 歌曲與故事

依用戶提供的歌曲、歌詞或 LRC 建立歌曲章節、情緒變化、故事卡和連續鏡頭時間表。切點由樂句、音樂事件、人物行動與新增資訊共同決定。沒有必要音訊或歌詞時先補齊關鍵輸入。

### 2. 全片導演規劃

先規劃故事狀態、主觀立場、情緒距離與景別、動能、空間、表演強度及光色，再拆成逐鏡計畫。副歌重複時，故事資訊、角色觀點或視覺關係也應推進。建立角色、服裝、場景、道具與狀態帳本。

### 3. 雙語資產與關鍵幀提示詞

按角色身份圖、全身三視圖、無人場景圖、必要道具圖及逐鏡首幀的順序撰寫。每份圖片提示詞都提供繁體中文與英文版本，並在提示詞外記錄資產 ID、用途、畫幅、目標尺寸、輸入圖片順序及各圖職責。兩版必須描述同一個可見畫面。

每鏡首幀需具有成立的承重與支撐、左右手與道具接觸、注意目標、光源、移動空間及下一動作方向。圖片尚未產出時，將這些列為生成後人工檢查項，不宣稱已檢查實圖。

### 4. 雙語 H3 提示詞

逐鏡編寫一份官方結構的英文 I2VA 提示詞，再寫語意一致的繁體中文對照版。英文版先寫官方首幀對齊首行，空一行後依序寫 integrated_multimodal_description、overall_soundscape、non_diegetic_music。每條提示詞只包含一個 [Shot 1]，從 <Picture 1> 的既有狀態發展為一個可見、連續、具結束狀態的事件。第一鏡不加內部切鏡時間碼；時長與歌曲絕對時間列在提示詞外的製作說明。

人物鏡頭從目標、注意轉移、動作預備、接觸受力到恢復構成因果鏈。攝影機運動須回應人物或資訊變化。現場聲與動作同步；overall_soundscape 概括本鏡環境、動作與非語言人物聲。英文與中文兩版的 non_diegetic_music 都寫 N/A。

### 5. 桌面版 HTML 交付

按照 references/output-format.md 輸出單一桌面版 HTML。頁面文字、標題、表格與製作說明一律使用繁體中文；圖片及 H3 提示詞以繁體中文、英文兩版並列，清楚標註英文 H3 為官方格式版、中文 H3 為對照版。使用 UTF-8 並安全轉義歌詞及提示詞。無須響應式版型、複製按鈕或多視口檢查。

## 交付檢查

依 references/final-audit.md 檢查鏡頭銜接、角色與道具連續性、首幀物理、雙語內容對應、英文 H3 官方格式與繁體中文 HTML。用戶要求修訂時，更新受影響的完整鏡頭區塊與兩種語言版本。
