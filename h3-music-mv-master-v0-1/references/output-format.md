# MV 交付格式：繁體中文桌面版 HTML

交付一份 UTF-8 HTML，頁面介面、章節、表格、備註與製作說明使用繁體中文。所有可提交模型的圖片提示詞和 H3 提示詞均附繁體中文、英文兩版；兩版描述同一素材與同一鏡頭。H3 英文版遵循官方 h3-prompt-writing 的模式結構；繁體中文版標示為對照版。

## 頁面內容

1. 製作設定：歌曲、畫幅、關鍵幀目標尺寸、預計使用的圖片與影片模型、H3 單鏡時長範圍，以及本流程只撰寫提示詞的邊界。
2. 故事與歌曲結構：一句話故事、角色目標與阻力、視覺章節、核心道具及結尾行動。
3. 全片導演規劃：故事、主觀、景別、動能、空間、表演與光色曲線，以及重要切鏡位置。
4. 角色、場景與道具：每項資產的 ID、用途、畫幅、目標尺寸、參考圖順序、繁體中文圖片提示詞、英文圖片提示詞與生成後人工檢查項。
5. 鏡頭時間表：鏡頭 ID、歌曲區間、時長、歌曲章節、故事動作、場景、關鍵幀 ID 與切鏡理由。
6. 逐鏡製作區塊：鏡頭任務、角色與道具狀態、首幀輸入圖順序、關鍵幀雙語提示詞、圖片到影片的動作路徑、H3 生成說明、英文 H3 正式版、繁體中文 H3 對照版及生成後人工檢查項。
7. 剪輯與聲音：原歌曲後期鋪入的位置、各鏡現場聲的保留方式及鏡頭之間的接法。

## 逐鏡呈現順序

- 鏡頭標題與歌曲區間。
- 本鏡故事任務、切入與離開理由。
- 首幀參考圖：依實際上傳順序標示每張圖的唯一職責。
- 關鍵幀提示詞：繁體中文與英文各一個完整文字區塊。尺寸、資產 ID 和檢查項寫在提示詞外。
- H3 生成說明：模式、生成時長、畫幅、<Picture 1> 的角色、聲音設定與前後鏡關係，寫在 H3 提示詞外。
- 英文 H3 正式版：保留官方首幀對齊首行、空行和三個標準欄位；欄位內容以英文撰寫。
- 繁體中文 H3 對照版：保留相同首行、欄位名、標籤與事件順序；欄位內容使用繁體中文。
- 生成後人工檢查項：身份、服裝、支撐、手部、道具、移動路徑、光線、場景及聲畫連續性。未產出的素材不寫成已檢查。

## 桌面版 HTML

- 只供 PC 閱讀。採單一固定寬度或最大寬度的置中內容區，雙語提示詞可用左右兩欄並列，長文字可在區塊內換行。
- 使用清楚的標題、目錄、表格及鏡頭卡片；中英文提示詞標籤醒目，避免把製作備註混入可提交模型的文字。
- 提示詞以保留換行的純文字容器呈現。歌詞、提示詞及用戶提供的文字須使用 textContent 或完整 HTML 轉義，避免 <Picture 1> 被當成標籤。
- 不需要響應式 CSS、行動版版型、複製按鈕、Clipboard 程式碼或多個視口寬度檢查。
- 只列真正完成的工作；若沒有產出實際圖片或影片，就保留「生成後人工檢查」字樣，不寫「已通過」。
